# Electric Vehicle Analysis Dashboard

## Project Overview
This Power BI dashboard analyzes electric vehicle data to understand market trends, vehicle types, manufacturers, county distribution, and CAFV eligibility.

## Tools Used
- Power BI
- DAX
- Excel

## Dashboard Features
- KPI Cards
- Interactive Filter Panel
- BEV vs PHEV Analysis
- County-wise Vehicle Analysis
- Manufacturer Analysis
- Model-wise Visualization
- Trend Analysis by Model Year
- CAFV Eligibility Analysis

## Key Insights
- Tesla has the highest number of electric vehicles.
- Battery Electric Vehicles (BEVs) dominate the market.
- EV growth increased rapidly after 2020.
- King County has the highest EV concentration.
